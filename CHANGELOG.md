# Журнал изменений

Изменения Quanta сгруппированы по выпускам.

## Unreleased

### Добавлено

- Проверка исходящих HTTP-запросов на SSRF, включая DNS-ответы и каждый редирект.
- Подтверждения для опасных цепочек с недоверенными данными и чтений чувствительных файлов.
- CSP без `unsafe-inline` и защищённое DPAPI-хранилище API-ключей.
- Описание модели безопасности и локальный отключённый пример MCP-сервера.
- Linux job CI, проверки Ruff и аудит Python-зависимостей через `pip-audit`.

### Исправлено

- Ключи API маскируются в ответах сервера и редактируются в логах.
- Нормализованы окончания строк исходных текстовых файлов.
