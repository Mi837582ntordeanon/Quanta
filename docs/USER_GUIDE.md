# Руководство пользователя Quanta

Quanta — приложение, «Кванта» — цифровая собеседница, Q.W.A.N.T.A. — Quantum Wireless And Neural Technology Assistant.

Локальное Windows-приложение для общения с Квантой — цифровой собеседницей с ярким, самостоятельным характером. Работает в отдельном окне Edge/Chrome, поддерживает Ollama и может выполнять действия на компьютере после подтверждения.

## Что уже работает

- **Чат с локальной моделью** через Ollama, стриминг ответов и tool-calling.
- **Три режима интерфейса:** мини-орб `480×740` (по умолчанию), обычное окно, полный HUD `1360×900`.
- **Характер:** живой тон и лёгкая ирония; стиль и обращение настраиваются, серьёзный режим приглушает шутки.
- **Файлы:** чтение, поиск, создание, копирование, перемещение; удаление — только в Корзину Windows.
- **ПК:** скриншоты, клики, ввод текста, горячие клавиши, громкость, буфер обмена, процессы.
- **Приложения:** каталог программ из меню «Пуск», запуск приложений, запуск portable `.exe` по пути, список открытых окон, штатный фокус и закрытие.
- **Windows UI Automation:** дерево доступных элементов окна, чтение названий/типов/Automation ID и управление кнопками, переключателями и полями. Перед действиями Кванта перечитывает дерево; поля паролей скрываются и недоступны для ввода.
- **Зрение ПК:** локальная модель Ollama Qwen3-VL анализирует снимок экрана; модель выбирается и загружается вручную во вкладке «Компьютер → Экран». По умолчанию предлагается `qwen3-vl:2b`; снимки отправляются только на Ollama с localhost.
- **Яндекс Музыка:** Кванта ищет точное название в установленном Electron-клиенте, запускает совпадение только при точном результате и проверяет плеер. Команда «Моя волна» открывает одноимённый раздел и сверяет состояние воспроизведения. Если клиент запущен без локального DevTools-порта, Кванта просит его окно закрыться штатно и запускает снова с портом, привязанным к `127.0.0.1`; принудительно процесс не завершает. Ключи и облачный API не нужны. Play/pause/next/previous идут через системные медиаклавиши и могут управлять активной медиасессией другого приложения.
- **Интернет:** поиск DuckDuckGo, загрузка страниц (с fallback через системный `curl` при проблемах с сертификатами).
- **Память, заметки и напоминания** с локальным хранением и ручным управлением. Поиск сначала работает без загрузок; семантическая модель включается отдельно в панели памяти и индексирует только явно сохранённые записи.
- **Проекты:** цель, статус, решения, файлы и следующий шаг сохраняются в карточке и подмешиваются в привязанные чаты; карточки можно создавать и обновлять в интерфейсе или через Кванту.
- **Очередь задач:** запросы выполняются последовательно, многошаговые планы и результаты инструментов сохраняются в карточках задач. После перезапуска зависшие задачи отмечаются как прерванные; их можно продолжить из панели «Задачи».
- **Выбор инструментов моделью:** вместо маршрутизации по regex Кванта показывает модели компактный каталог, а она выбирает нужные функции по смыслу запроса.
- **MCP:** пользовательские stdio-серверы можно подключать из `data/mcp_servers.json`. MCP-команды запускаются без shell; каждый вызов внешнего инструмента требует подтверждения.
- **Сценарии**: встроенные и пользовательские команды доступны одной кнопкой.
- **Журнал действий** с безопасной отменой создания или перемещения небольших файлов.
- **Диагностика** Ollama, голосового движка, свободной RAM/диска и горячей клавиши.
- **Быстрый вызов** окна сочетанием `Ctrl+Alt+Space` (можно отключить в настройках).
- **Погода** для Краснодара (Яндекс.Погода, fallback Open-Meteo).
- **STL-модели** и **генерация изображений**.
- **Minecraft:** создание/запуск локальных Vanilla Java-серверов, логи и консоль. Mineflayer-компаньон может войти на управляемый локальный offline-mode сервер, показать координаты, здоровье, игроков и ближайших существ, а также писать в игровой чат.
- **HUD:** часы, погода, CPU/RAM/диск, батарея, uptime, активное окно.
- **Режимы доступа:** «Безопасный», «Умный» и «Авто»; команды и прочие высокорисковые действия требуют подтверждения во всех режимах.
- **Подтверждения** для записи/удаления файлов, команд, ввода, скриншотов и буфера.
- **Локальные данные:** `data/`; сервер слушает только `127.0.0.1` (по умолчанию порт 8765, при занятости — следующий свободный).

Для более быстрой работы Ollama Кванта сначала передаёт компактный каталог, а схемы выбранных инструментов добавляет только после запроса модели. Это требует дополнительного короткого шага модели, если задача использует инструменты. Очередь не допускает параллельной загрузки нескольких моделей чата. Настраиваются контекст 8K/12K/16K и удержание модели 2/5/10 минут. При запуске выбранная модель по умолчанию прогревается в фоне; прогрев можно отключить в настройках. На системе с 8 ГБ видеопамяти стартовые значения — 12K и 5 минут. Скорость зависит от модели и свободной памяти. Резервная модель настраивается отдельно и выключена по умолчанию.

## Управление компьютером

На боковой панели есть раздел **«Компьютер»**: поиск программ из меню «Пуск», открытие выбранной программы или `.exe` по указанному пути, переключение между окнами, штатное закрытие и дерево UI Automation. Действия из чата в умном режиме запрашивают подтверждение; действия, нажимаемые пользователем в самой панели, выполняются напрямую.

Вкладка **«Экран»** использует Windows UI Automation и установленную локальную Ollama. Qwen3-VL не скачивается при запуске: выбери модель и нажми «Загрузить». Нужна Ollama 0.12.7 или новее. Для большинства систем начни с `qwen3-vl:2b` (~1,9 ГБ); `4b` занимает ~3,3 ГБ, а `8b` — ~6,2 ГБ и заметно требовательнее к видеопамяти. Размеры и требования сверяй с [каталогом моделей Ollama](https://ollama.com/library/qwen3-vl). При анализе скриншот передаётся только на локальный адрес Ollama и хранится в локальной папке `data/media/screenshots` (оставляются последние 10 снимков Quanta Vision); результат виден в панели и чате. Текст из окон и изображений считается недоверенным; не поручай модели вводить пароли и коды.

## Minecraft-серверы

Раздел **«Minecraft-серверы»** управляет локальными Vanilla Java серверами. Кванта получает версию и `server.jar` с доменов Mojang и сверяет SHA-1 перед запуском; официальный файл доступен на [странице серверного ПО Minecraft](https://www.minecraft.net/en-us/download/server). Совместимая Java определяется в PATH и среди runtime, скачанных Minecraft Launcher; если runtime отсутствует, сначала запусти Launcher или установи Java отдельно. Перед созданием требуется вручную отметить принятие [Minecraft EULA](https://www.minecraft.net/en-us/eula). По умолчанию сервер слушает только `127.0.0.1`; доступ к локальной сети выключен. Серверы создаются в режиме `online-mode=false` для офлайн-тестов, поэтому их нельзя публиковать в интернете: имена игроков не проверяются. Работающий сервер не будет остановлен автоматическим таймером простоя Кванты; при штатном закрытии самого приложения он завершится.

В карточке запущенного сервера можно включить Mineflayer-компаньона. Он подключается только к `127.0.0.1` и только к серверу, созданному Квантой; аккаунт Microsoft не используется. Панель показывает его здоровье, сытость, координаты, игроков и существ рядом. Игровые сообщения можно отправлять вручную; команды сервера через чат заблокированы. Нужен Node.js 22+ и один раз `npm install` в папке проекта. Сейчас это панель-компаньон в интерфейсе Кванты для Vanilla Java; модифицированные сборки, строительные действия и внутриигровой оверлей не входят в текущую версию.

В верхней панели есть профили ресурсов **Работа** и **Игра**. Игровой профиль прекращает прогрев, выгружает резидентные голосовые модели и выбранную модель Ollama, сокращает контекст чата до 8K, удерживает модель не дольше двух минут и запускает распознавание Whisper на CPU. Рабочий профиль возвращает значения из настроек и подготавливает голос/чат в фоне, если хватает свободной памяти. Во время переключения новые запросы чата и голосовые операции временно отклоняются, чтобы не загружать модель одновременно с её выгрузкой.

## MCP-серверы

MCP-серверы не запускаются, пока не создан файл `data/mcp_servers.json`. Скопируй `mcp_servers.example.json` из корня проекта: в нём находится локальный echo-сервер `tools/mcp_example_server.py`, но он помечен `"enabled": false`. Чтобы проверить его в исходном checkout, установи `requirements.txt`, включи сервер (`true`) и перезапусти обнаружение MCP-инструментов. Конфигурация не исполняется, пока MCP-сервер выключен.

Для своего stdio-сервера используй такую форму конфигурации и укажи существующие команду, файл и рабочую папку:

```json
{
  "servers": [
    {
      "name": "my-tools",
      "enabled": false,
      "command": "node",
      "args": ["C:\\Tools\\my-mcp-server\\server.js"],
      "cwd": "C:\\Tools\\my-mcp-server",
      "env": {}
    }
  ]
}
```

Команда не запускается через shell, переменные окружения передаются только из `env`, а stderr сервера не попадает в протокол. MCP-инструменты помечаются высокорисковыми и каждый вызов показывает подтверждение. Описание и ответы внешнего сервера считаются недоверенными. В режиме «Безопасный» внешние MCP-инструменты не доступны. SDK ставится командой `py -3.11 -m pip install -r requirements.txt`.

## Семантическая память

Заметки остаются локальными. Обычный лексический поиск работает сразу. Чтобы включить поиск по смыслу, установи `requirements.txt`, открой панель **«Память»** и нажми **«Включить · скачать модель»**. Кванта скачает multilingual MiniLM в `data/models/embeddings`, построит локальный индекс и не отправляет текст заметок наружу. Модель около 220 МБ загружается только после нажатия; при отсутствии сети остаётся лексический поиск. Удаление заметки удаляет и её сохранённый вектор. [Модель FastEmbed](https://qdrant.github.io/fastembed/examples/Supported_Models/) — Apache-2.0.

## Резервная модель

В настройках **«Нейроядро»** можно включить резервный маршрут и задать до пяти последовательных локальных или OpenAI-compatible моделей. После ошибки подключения, лимита запросов или временной ошибки сервера Кванта пробует следующий маршрут, пока ещё не показала первый токен. Ошибки авторизации и неизвестная модель требуют исправить настройки; после начала ответа генерация не повторяется. Доступные бесплатные квоты зависят от выбранного провайдера и здесь не гарантируются. Если добавить внешние API, Кванта отправит им текст задачи и контекст чата — включай только доверенные сервисы.

Можно также включить **уточнение многошагового плана** первой резервной моделью. Маленькая основная модель остаётся на обычный чат; планировщик видит запрос и черновой план, но не инструменты и не может выполнять действия. Затем Кванта остановится и покажет план, рабочую папку, разрешение на запись и точный список команд для одобрения. Эта опция выключена по умолчанию.

Дополнительный пул задаётся JSON-массивом, например:

```json
[
  {"provider": "openai", "api_url": "https://example.invalid/v1", "model": "модель-1", "api_key": "ключ"},
  {"provider": "ollama", "model": "qwen3:8b"}
]
```

В настройках есть кнопка для подготовки маршрута OpenRouter `openrouter/free`: он сам выбирает бесплатную чат-модель, доступную в момент запроса. Нужен личный API-ключ; Кванта не создаёт его и не отправляет запросы, пока резерв не включён пользователем. OpenRouter меняет доступные модели и ограничения; текущие сведения смотри в [официальном каталоге free-моделей](https://openrouter.ai/collections/free-models). Используй облачный резерв только для запросов, содержимое которых можно передавать выбранному провайдеру.

Для основного DeepSeek API есть отдельная кнопка подготовки настроек. Она подставляет OpenAI-совместимый адрес `https://api.deepseek.com` и модель `deepseek-flash` согласно [официальной документации DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/). Добавь личный API-ключ и сохрани настройки, чтобы переключить основной провайдер на DeepSeek. Запросы тарифицируются провайдером. Название модели и цены могут меняться — сверяй их с официальным каталогом перед использованием.

Маршруты проверяются по очереди после основного резервного маршрута. API-ключи хранятся отдельно в `data/api_secrets.json`, зашифрованном DPAPI текущей учётной записи Windows; интерфейс получает только маску. Не коммить каталог `data/`.

## Запуск

1. Установи **Python 3.11**, **Ollama**, **Edge/Chrome** и **CUDA-драйвер NVIDIA**.
2. Установи зависимости приложения и, если нужен локальный голос, зависимости обработки речи:
   ```cmd
   py -3.11 -m pip install -r requirements.txt
   py -3.11 -m pip install -r requirements-voice.txt
   ```
   Для Minecraft-компаньона дополнительно установи Node.js 22+ и выполни `npm install`.
3. Скачай модель:
   ```cmd
   ollama pull qwen3:4b-instruct
   ```
4. Запусти `Запустить.bat` двойным кликом.
5. Откроется мини-окно Кванты. Кнопка `⤢` разворачивает HUD, шестерёнка открывает настройки.

Если Ollama не запущена, открой терминал и выполни:
```cmd
ollama serve
```

Проверить вручную:
```cmd
py -3.11 server.py
```
Затем открой `http://127.0.0.1:8765/?view=mini` или `?view=hud`. Если порт 8765 занят другой программой, лончер сам выберет свободный и откроет правильный адрес; фактический порт записывается в `data/port.txt`.

## Сборка Windows-приложения

Для локальной сборки нужны Python 3.11, Node.js 22, `npm ci` и Inno Setup 7. Скрипт `build_windows.ps1` создаёт отдельную временную Python-среду, собирает `dist/Quanta/Quanta.exe` и компилирует `dist/Quanta-Setup.exe`. Установщик работает без прав администратора и кладёт программу в `%LOCALAPPDATA%\Programs\Quanta`; чаты, настройки и загруженные модели остаются в `%LOCALAPPDATA%\Quanta\data` и не удаляются при деинсталляции. Голосовые веса не входят в установщик.

В сборке Mineflayer остаётся только для Minecraft Java: метаданные Bedrock и файлы документации/тестов отбрасываются, что убирает сотни мегабайт лишних данных. Для работы компаньона нужен Node.js 22 или новее. Запуск приложения открывает отдельное окно Edge/Chrome без вкладок браузера. Системная Ollama и её модели ставятся отдельно.

Сборка:

```powershell
npm ci
powershell -NoProfile -File .\build_windows.ps1
```

Кванта не использует `ExecutionPolicy Bypass` для запуска пользовательских команд.

## Управление

| Действие | Горячая клавиша |
|---|---|
| Отправить | `Enter` |
| Новая строка | `Shift+Enter` |
| Фокус в поле ввода | `Ctrl+Space` |
| Новый чат | `Ctrl+K` |
| Закрыть окно/модалку | `Esc` |

В мини-режиме кнопка `☰` открывает историю чатов, заметки и напоминания. В обычном окне и HUD сайдбар виден постоянно.

## Режимы доступа

- **Безопасный** — чтение и безопасные действия; изменения и команды блокируются.
- **Умный** — опасные действия требуют подтверждения. Рекомендуется по умолчанию.
- **Авто** — чтение и низкорисковые действия идут без подтверждения. Команды, запуск приложений, ввод текста, запись/удаление и другие высокорисковые действия всё равно спрашивают разрешение.

Подтверждение показывает имя инструмента, аргументы и предупреждение. Кнопка «Отклонить» безопасна: инструмент не выполняется, задача приостанавливается, а остальные действия из того же ответа модели отменяются. Для многошагового плана Кванта сначала покажет шаги и запросит отдельное одобрение. Запись файлов можно ограничить выбранной папкой. Для команд Кванта поддерживает Windows Sandbox: отдельная гостевая система без сети, буфера обмена и доступа к файлам хоста за пределами явно расшаренной папки. Изменения внутри расшаренной папки сохраняются на хосте. Если Sandbox выключен, перечисленные в плане команды каждый раз требуют отдельного подтверждения и запускаются с правами текущего пользователя. Для включения компонента Windows Sandbox в Windows 10/11 Pro открой PowerShell от имени администратора и выполни `Enable-WindowsOptionalFeature -Online -FeatureName Containers-DisposableClientVM -All`, затем перезагрузи Windows. [Документация Microsoft](https://learn.microsoft.com/windows/security/application-security/application-isolation/windows-sandbox/windows-sandbox-install). API требует случайный токен текущего процесса; Origin сверяется с Host и портом приложения.

## Данные

Всё лежит в `data/`:

- `settings.json` — настройки;
- `chats/` — история чатов;
- `projects.json` — карточки проектов и привязки чатов;
- `tasks.json` — планы, очередь и checkpoints выполнения;
- `memory.json` — явно сохранённые сведения о предпочтениях;
- `memory_vectors.json` — локальные эмбеддинги заметок для семантического поиска;
- `models/embeddings/` — скачанные локальные веса семантической модели;
- `mcp_servers.json` — необязательные команды пользовательских MCP-серверов;
- `notes.json`, `reminders.json` — заметки и напоминания;
- `media/` — скриншоты, картинки, STL;
- `minecraft/` — версии Vanilla-серверов, миры и логи;
- `browser_profile/` — профиль окна Edge;
- `server.out.log`, `quanta.log` — журналы.

Удаление файлов через Кванту идёт в Корзину. Пароли и содержимое буфера не сохраняются в заметках автоматически. Скрытого кейлоггера нет.

## Модели

По умолчанию:
- `qwen3:4b-instruct` — основной чат: быстрый, без режима рассуждений, с нативным вызовом инструментов;
- `qwen3:8b` / `qwen3:14b` — сложные задачи (медленнее, если хватает VRAM);
- `qwen2.5-coder:7b` — код.

Модель переключается в верхней панели или в настройках. Можно задать резервную модель для перебоя с основным провайдером; никаких облачных запросов без включения резерва не делается. При нехватке VRAM Ollama может выгружать модель дольше — это нормально.

Окно контекста — 16k токенов. История и крупные результаты инструментов обрезаются по бюджету, чтобы Ollama не выбросила системный промпт и персона не ломалась в длинных чатах.

## Голос

Quanta использует локальный нативный движок Qwen-TTS Studio и модель **Qwen-Talker 1.7B VoiceDesign Q8_0**. Python/PyTorch не участвуют в синтезе: это экономит время запуска и память по сравнению с отдельной Python-сборкой. Модель ищется в `%LOCALAPPDATA%\Speech Studio\models\qwen3-tts`; Q8_0 выбирается первым, если файл установлен. DLL движка берётся из `%ProgramFiles%\qwen-tts-studio`.

Промпт из `промт для голоса.txt` встроен как профиль по умолчанию и передаётся VoiceDesign при каждом синтезе. Поле «Описание голоса» позволяет менять его в настройках. Русский задаётся движку явно; если модель или DLL не найдены, API возвращает ошибку вместо незаметной подмены на другой, роботизированный голос.

Перед TTS отдельная копия реплики проходит локальную нормализацию: `num2words` читает числа, `pymorphy3` согласует их с ближайшим существительным, даты и время раскрываются словами, а `RUAccent` добавляет русские метки ударения. Цифры внутри названий моделей и версий сохраняются. Эти настройки можно выключить раздельно в разделе «Голос». RUAccent скачивает свои словари/модели (~194 МБ) при первом запуске обработки, затем работает локально; для установки Python-пакетов есть `requirements-voice.txt`. Чтобы не держать модель ударений в памяти, она выгружается после трёх минут без голосовых запросов. У Qwen нет гарантии, что метки `+` будут менять произношение каждого слова, поэтому автоударения отключаются одним переключателем.

**Silero v4 RU**, **Qwen3-TTS CustomVoice** и **VoxCPM2** оставлены как переключаемые альтернативы. **faster-whisper** распознаёт локально речь из кнопки push-to-talk через `/api/voice/transcribe`; устройство по умолчанию — Auto: CUDA, если доступна и хватает видеопамяти, иначе CPU. CPU/GPU для распознавания задаётся отдельно от TTS. Браузер просит включить шумоподавление и эхоподавление микрофона; автоуровень громкости также настраивается. После записи Quanta показывает фактические эффекты, которые браузер сообщает для аудиодорожки. Qwen-Talker отдельно может прогнать сгенерированный WAV через лёгкий FFmpeg `afftdn`; фильтр выключается в настройках и при ошибке оставляет оригинал. Он уменьшает фоновый шум, но не исправляет темп или интонацию самой модели. После ответа UI запрашивает TTS и воспроизводит WAV через локальный media route. Статус в настройках показывает наличие/загрузку Qwen-Talker и выбранный backend.

Фоновый прогрев загружает нативный движок и веса без тестовой фразы; модель остаётся в памяти worker-процесса для последующих реплик. Перед загрузкой Q8 Quanta проверяет свободную RAM и оставляет запас: при объёме меньше 4 ГБ синтез откладывается с понятной ошибкой, особенно если открыт Qwen-TTS Studio. На этой машине Qwen-Talker работает на CPU: установленный CUDA backend видит GTX 1070, но не содержит ядра для её compute capability 6.1. Это ограничение TTS-библиотеки; чат Ollama использует GPU. Отдельный worker изолирует нативные сбои от HTTP-сервера Quanta.

## Если что-то не работает

- **Порт 8765 занят** — Кванта автоматически возьмёт следующий свободный порт (диапазон 8765–8784). Фактический порт смотри в `data/port.txt` или задай свой через `QUANTA_PORT`.
- **Ollama не отвечает** — проверь `http://127.0.0.1:11434` и `ollama list`.
- **Окно не открылось** — проверь наличие Edge/Chrome; `launcher.py` умеет fallback в браузер по умолчанию.
- **Погода/поиск/картинки не работают** — проверь интернет; погода имеет fallback Яндекс/Open-Meteo, загрузка страниц — fallback через `curl.exe`.
- **Первый ответ долгий** — после запуска модель и промпт загружаются 5–10 секунд; дальше ответы обычно занимают 1–5 секунд. Thinking-модели (`qwen3:8b` и старше) могут отвечать заметно дольше — для быстрых задач оставь `qwen3:4b-instruct`.
