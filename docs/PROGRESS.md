## Известные проблемы и ограничения

- Рабочее дерево было существенно изменено до начала этапного оформления; происхождение всех исходных изменений не установлено. Чувствительные и пользовательские файлы сохранены и исключаются из коммитов.
- Windows Sandbox, UI Automation, упаковка и установщик требуют отдельной проверки на Windows после соответствующих этапов.
- Этапные Linux и Windows jobs ещё ожидают запуска после публикации коммитов; локальный Linux-прогон через WSL недоступен, так как дистрибутив отсутствует.
- В коммиты не включены `AGENTS.md`, `api_secrets.json`, пользовательские данные в `data/` и локальные диагностические файлы.
- Три существовавших локальных файла разовой диагностики (`_voice_blob_check.py`, `_voice_fs_check.py`, `Текстовый документ.txt`) не удалялись; их прежние точечные ignore-правила убраны, чтобы `.gitignore` не содержал локальные следы.
- Нативные Windows UI Automation и действия с ПК не проверялись: тесты не выполняли реальный ввод. Ручная проверка: запустить `python server.py`, открыть локальный интерфейс, проверить список приложений; в режиме smart запросить действие с подтверждением и отклонить его; запросить чтение чувствительного пути и проверить предупреждение.
- Метки taint очищаются между ходами `Agent.run`, поэтому чтение в прошлом сообщении само по себе не потребует подтверждения в новом ходе. MCP-вызовы и HTTP(S)-URL через `open_path` считаются сетевыми; остальные инструменты классифицируются по `@tool.network` (значение по умолчанию — `True`).
- Факты аудита безопасности подтверждены: `fetch_url`/`read_file` имеют риск `read`, `memory_save` — `low`; специальные проверки добавляют подтверждение в опасных цепочках. Токен создаётся на процесс и подставляется при отдаче HTML, а в статическом `index.html` находится только placeholder. В `ui/app.js` остаётся 47 присваиваний `innerHTML`.
- Архитектурные факты аудита по монолитам, JSON-хранилищу, CI, eval и обновлению относятся к последующим этапам и здесь не изменялись.
- Сетевые запросы локальных Ollama/API-провайдеров не менялись. Прямое открытие URL в браузере остаётся отдельным подтверждаемым действием пользователя; автоматический браузерный механизм не используется как серверный загрузчик страницы.

- Сохранять всё содержимое существующего рабочего дерева и редактировать только файлы, необходимые для текущего пункта.

- Не удалять данные и не выполнять сетевые действия приложения в ходе проверок.
