# Quanta

Quanta — приложение, «Кванта» — цифровая собеседница, Q.W.A.N.T.A. — Quantum Wireless And Neural Technology Assistant.

Локальный Windows-ассистент с голосом, Ollama, управлением ПК и подтверждением опасных действий.

## Быстрый старт

Требуются Windows 10/11, Python 3.11, Ollama и Edge или Chrome.

1. Установи Ollama и скачай модель чата:
   ```cmd
   ollama pull qwen3:4b-instruct
   ```
2. Запусти `Запустить.bat` из папки проекта. Кванта откроется в мини-окне; кнопка `⤢` разворачивает HUD.
3. Если Ollama ещё не запущена, выполни `ollama serve` в терминале.

Для MCP и семантического поиска установи `py -3.11 -m pip install -r requirements.txt`. Голосовая обработка и Minecraft-компаньон подключаются отдельно; смотри руководство.

Для запуска без окна используй `py -3.11 server.py`, затем открой `http://127.0.0.1:8765/?view=mini`. При занятом порте лончер выберет следующий свободный.
