# Q.W.A.N.T.A. — Кванта

**Quantum Wireless And Neural Technology Assistant**

Локальное Windows-приложение для общения с Квантой — цифровой собеседницей с ярким, самостоятельным характером. Работает в отдельном окне Edge/Chrome, поддерживает Ollama и может выполнять действия на компьютере после подтверждения.

## Что уже работает

- **Чат с локальной моделью** через Ollama, стриминг ответов и tool-calling.
- **Три режима интерфейса:** мини-орб `480×740` (по умолчанию), обычное окно, полный HUD `1360×900`.
- **Характер:** живой тон и лёгкая ирония; стиль и обращение настраиваются, серьёзный режим приглушает шутки.
- **Файлы:** чтение, поиск, создание, копирование, перемещение; удаление — только в Корзину Windows.
- **ПК:** скриншоты, клики, ввод текста, горячие клавиши, громкость, буфер обмена, процессы.
- **Интернет:** поиск DuckDuckGo, загрузка страниц (с fallback через системный `curl` при проблемах с сертификатами).
- **Память, заметки и напоминания** с локальным хранением и ручным управлением памятью.
- **Проекты:** цель, статус, решения, файлы и следующий шаг сохраняются в карточке и подмешиваются в привязанные чаты; карточки можно создавать и обновлять в интерфейсе или через Кванту.
- **Сценарии**: встроенные и пользовательские команды доступны одной кнопкой.
- **Журнал действий** с безопасной отменой создания или перемещения небольших файлов.
- **Диагностика** Ollama, голосового движка, свободной RAM/диска и горячей клавиши.
- **Быстрый вызов** окна сочетанием `Ctrl+Alt+Space` (можно отключить в настройках).
- **Погода** для Краснодара (Яндекс.Погода, fallback Open-Meteo).
- **STL-модели** и **генерация изображений**.
- **Minecraft:** проверка статуса Java-сервера по `host:port`.
- **HUD:** часы, погода, CPU/RAM/диск, батарея, uptime, активное окно.
- **Режимы доступа:** «Безопасный», «Умный» (опасное — с подтверждением), «Авто».
- **Подтверждения** для записи/удаления файлов, команд, ввода, скриншотов и буфера.
- **Локальные данные:** `data/`; сервер слушает только `127.0.0.1` (по умолчанию порт 8765, при занятости — следующий свободный).

Для более быстрой работы Ollama Кванта передаёт только инструменты, подходящие к текущей просьбе, хранит индекс списка чатов, настраивает контекст 8K/12K/16K и время удержания модели 2/5/10 минут. При запуске выбранная модель по умолчанию прогревается в фоне после голосового движка; прогрев можно отключить в настройках, если нужно освободить видеопамять. На системе с 8 ГБ видеопамяти стартовые значения — 12K и 5 минут. Скорость загрузки и генерации зависит от модели и свободной памяти.

В верхней панели есть профили ресурсов **Работа** и **Игра**. Игровой профиль прекращает прогрев, выгружает резидентные голосовые модели и выбранную модель Ollama, сокращает контекст чата до 8K, удерживает модель не дольше двух минут и запускает распознавание Whisper на CPU. Рабочий профиль возвращает значения из настроек и подготавливает голос/чат в фоне, если хватает свободной памяти. Во время переключения новые запросы чата и голосовые операции временно отклоняются, чтобы не загружать модель одновременно с её выгрузкой.

## Запуск

1. Установи **Python 3.11**, **Ollama**, **Edge/Chrome** и **CUDA-драйвер NVIDIA**.
2. Установи локальные зависимости:
   ```cmd
   py -3.11 -m pip install qwen-tts faster-whisper soundfile
   ```
3. Скачай модель:
   ```cmd
   ollama pull qwen3:4b-instruct
   ```
4. Запусти `Запустить.bat` двойным кликом.
5. Откроется мини-окно Кванты. Кнопка `⤢` разворачивает HUD, шестерёнка открывает настройки.

Если Ollama не запущена, открой терминал и выполни:
```cmd
ollama serve
```

Проверить вручную:
```cmd
py -3.11 server.py
```
Затем открой `http://127.0.0.1:8765/?view=mini` или `?view=hud`. Если порт 8765 занят другой программой, лончер сам выберет свободный и откроет правильный адрес; фактический порт записывается в `data/port.txt`.

## Управление

| Действие | Горячая клавиша |
|---|---|
| Отправить | `Enter` |
| Новая строка | `Shift+Enter` |
| Фокус в поле ввода | `Ctrl+Space` |
| Новый чат | `Ctrl+K` |
| Закрыть окно/модалку | `Esc` |

В мини-режиме кнопка `☰` открывает историю чатов, заметки и напоминания. В обычном окне и HUD сайдбар виден постоянно.

## Режимы доступа

- **Безопасный** — чтение и безопасные действия; изменения и команды блокируются.
- **Умный** — опасные действия требуют подтверждения. Рекомендуется по умолчанию.
- **Авто** — без подтверждений. Включай только если понимаешь последствия.

Подтверждение показывает имя инструмента, аргументы и предупреждение. Кнопка «Отклонить» безопасна: инструмент не выполняется.

## Данные

Всё лежит в `data/`:

- `settings.json` — настройки;
- `chats/` — история чатов;
- `projects.json` — карточки проектов и привязки чатов;
- `notes.json`, `reminders.json` — заметки и напоминания;
- `media/` — скриншоты, картинки, STL;
- `browser_profile/` — профиль окна Edge;
- `server.out.log`, `quanta.log` — журналы.

Удаление файлов через Кванту идёт в Корзину. Пароли и содержимое буфера не сохраняются в заметках автоматически. Скрытого кейлоггера нет.

## Модели

По умолчанию:
- `qwen3:4b-instruct` — основной чат: быстрый, без режима рассуждений, с нативным вызовом инструментов;
- `qwen3:8b` / `qwen3:14b` — сложные задачи (медленнее, если хватает VRAM);
- `qwen2.5-coder:7b` — код.

Модель переключается в верхней панели или в настройках. При нехватке VRAM Ollama может выгружать модель дольше — это нормально.

Окно контекста — 16k токенов. История и крупные результаты инструментов обрезаются по бюджету, чтобы Ollama не выбросила системный промпт и персона не ломалась в длинных чатах.

## Голос

Quanta использует локальный нативный движок Qwen-TTS Studio и модель **Qwen-Talker 1.7B VoiceDesign Q8_0**. Python/PyTorch не участвуют в синтезе: это экономит время запуска и память по сравнению с отдельной Python-сборкой. Модель ищется в `%LOCALAPPDATA%\Speech Studio\models\qwen3-tts`; Q8_0 выбирается первым, если файл установлен. DLL движка берётся из `%ProgramFiles%\qwen-tts-studio`.

Промпт из `промт для голоса.txt` встроен как профиль по умолчанию и передаётся VoiceDesign при каждом синтезе. Поле «Описание голоса» позволяет менять его в настройках. Русский задаётся движку явно; если модель или DLL не найдены, API возвращает ошибку вместо незаметной подмены на другой, роботизированный голос.

Перед TTS отдельная копия реплики проходит локальную нормализацию: `num2words` читает числа, `pymorphy3` согласует их с ближайшим существительным, даты и время раскрываются словами, а `RUAccent` добавляет русские метки ударения. Цифры внутри названий моделей и версий сохраняются. Эти настройки можно выключить раздельно в разделе «Голос». RUAccent скачивает свои словари/модели (~194 МБ) при первом запуске обработки, затем работает локально; для установки Python-пакетов есть `requirements-voice.txt`. Чтобы не держать модель ударений в памяти, она выгружается после трёх минут без голосовых запросов. У Qwen нет гарантии, что метки `+` будут менять произношение каждого слова, поэтому автоударения отключаются одним переключателем.

**Silero v4 RU**, **Qwen3-TTS CustomVoice** и **VoxCPM2** оставлены как переключаемые альтернативы. **faster-whisper** распознаёт локально речь из кнопки push-to-talk через `/api/voice/transcribe`; устройство по умолчанию — Auto: CUDA, если доступна и хватает видеопамяти, иначе CPU. CPU/GPU для распознавания задаётся отдельно от TTS. Браузер просит включить шумоподавление и эхоподавление микрофона; автоуровень громкости также настраивается. После записи Quanta показывает фактические эффекты, которые браузер сообщает для аудиодорожки. Qwen-Talker отдельно может прогнать сгенерированный WAV через лёгкий FFmpeg `afftdn`; фильтр выключается в настройках и при ошибке оставляет оригинал. Он уменьшает фоновый шум, но не исправляет темп или интонацию самой модели. После ответа UI запрашивает TTS и воспроизводит WAV через локальный media route. Статус в настройках показывает наличие/загрузку Qwen-Talker и выбранный backend.

Фоновый прогрев загружает нативный движок и веса без тестовой фразы; модель остаётся в памяти worker-процесса для последующих реплик. Перед загрузкой Q8 Quanta проверяет свободную RAM и оставляет запас: при объёме меньше 4 ГБ синтез откладывается с понятной ошибкой, особенно если открыт Qwen-TTS Studio. На этой машине Qwen-Talker работает на CPU: установленный CUDA backend видит GTX 1070, но не содержит ядра для её compute capability 6.1. Это ограничение TTS-библиотеки; чат Ollama использует GPU. Отдельный worker изолирует нативные сбои от HTTP-сервера Quanta.

## Если что-то не работает

- **Порт 8765 занят** — Кванта автоматически возьмёт следующий свободный порт (диапазон 8765–8784). Фактический порт смотри в `data/port.txt` или задай свой через `QUANTA_PORT`.
- **Ollama не отвечает** — проверь `http://127.0.0.1:11434` и `ollama list`.
- **Окно не открылось** — проверь наличие Edge/Chrome; `launcher.py` умеет fallback в браузер по умолчанию.
- **Погода/поиск/картинки не работают** — проверь интернет; погода имеет fallback Яндекс/Open-Meteo, загрузка страниц — fallback через `curl.exe`.
- **Первый ответ долгий** — после запуска модель и промпт загружаются 5–10 секунд; дальше ответы обычно занимают 1–5 секунд. Thinking-модели (`qwen3:8b` и старше) могут отвечать заметно дольше — для быстрых задач оставь `qwen3:4b-instruct`.
