# Безопасность Quanta

Этот документ описывает границы защиты локального Windows-приложения Quanta. Он не обещает защиту от вредоносного кода, который уже выполняется с правами той же учётной записи Windows.

## Что защищается

- API-ключи провайдеров: хранятся отдельно от `settings.json` в `data/api_secrets.json`, зашифрованном Windows DPAPI для текущей учётной записи. В ответах API и журнале ключи маскируются. Остальные локальные данные Quanta — чаты, память, заметки и настройки — хранятся в `data/` обычными файлами и этим шифрованием не покрываются.
- Локальный API и действия с компьютером: сервер привязывается к `127.0.0.1`. Для `/api/*` проверяются Host, соответствующий Origin (если он передан) и случайный токен процесса, который интерфейс получает через HTML.
- Интерфейс браузера: сервер отдаёт CSP без `unsafe-inline`; скрипты и стили загружаются с текущего origin. `data:` и `blob:` разрешены для изображений, `blob:` — для медиа.
- Внешние HTTP-запросы инструментов: URL и DNS-ответы проверяются; локальные и специальные адреса запрещены, перенаправления перепроверяются, соединение закрепляется за проверенным публичным IP. Запросы к адресу Ollama из настроек этим фильтром намеренно не меняются.

## Недоверенные данные

Содержимое файлов, буфера обмена, снимков экрана, дерева UI Automation, страниц и результатов веб-поиска, ответов провайдеров и инструментов MCP считается данными, а не инструкциями. Модель может ошибаться или получать в этих материалах намеренно вредные указания. Записи памяти также рассматриваются как данные пользователя, а не как системные правила.

Успешное чтение локальных данных помечает текущий ход. Если в этом же ходе модель пытается отправить данные наружу сетевым инструментом, приложение запрашивает подтверждение, показывает назначение и предупреждает о возможной утечке. Чтение чувствительного пути и сохранение памяти после недоверенного результата также требуют подтверждения. Каждый вызов внешнего инструмента MCP подтверждается отдельно.

## Режимы доступа и подтверждения

- **Безопасный:** инструменты высокого риска заблокированы.
- **Умный:** действия с высоким риском и инструменты, отмеченные для подтверждения, спрашивают разрешение перед запуском.
- **Авто:** часть чтения и низкорисковых действий выполняется без вопроса. Высокий риск, вызовы MCP и описанные выше проверки цепочек доверия всё равно требуют подтверждения.

Подтверждение относится к показанному действию и его аргументам. Проверь путь, URL, команду, окно или другое назначение до ответа. Одобрение плана задачи ограничено указанной в нём папкой и разрешёнными действиями. Безопасный режим блокирует высокий риск, а не превращает его в подтверждаемый запуск.

## Пределы модели угроз

- Quanta рассчитана на локальный компьютер и одного пользователя. Токен сессии защищает API от посторонних веб-страниц, но не является границей безопасности от другого процесса той же учётной записи, расширения браузера с доступом к странице, вредоносного ПО или уже скомпрометированного профиля Windows.
- DPAPI защищает сохранённые API-ключи от чтения файла вне контекста пользователя. Во время работы ключи расшифрованы в памяти; компрометация учётной записи или работа в разблокированном сеансе выходит за пределы защиты DPAPI.
- Если в настройках выбран внешний API-провайдер, текст запроса и переданный ему контекст отправляются этому провайдеру. Локальная модель Ollama и внешний провайдер имеют разные границы доверия.
- Подтверждение снижает риск случайного действия, но само по себе не доказывает безопасность команды или достоверность результата.
- Интерфейс по-прежнему строит часть разметки через 47 присваиваний `innerHTML`. CSP не очищает HTML-значения и не заменяет экранирование данных перед вставкой в разметку.
